# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and, when applicable, the latest published release. Older releases are not guaranteed to receive security updates.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting flow for this repository:

1. Open the repository's **Security** tab.
2. Open **Advisories**.
3. Choose **Report a vulnerability**.

Include, when possible:

- A clear description of the issue.
- The affected version, commit, or URL.
- Minimal reproduction steps.
- The potential impact.
- Any suggested mitigation or fix.

Please avoid including real resume data, credentials, tokens, or other unnecessary personal information.

The maintainer will review reports in good faith, coordinate a fix when needed, and publish an advisory when appropriate.
