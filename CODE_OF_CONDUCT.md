# Code of Conduct

Resume Craft aims to be a welcoming, constructive open-source community.

## Expected behavior

Participants should:

- Be respectful and patient with people of different backgrounds and experience levels.
- Discuss ideas and code rather than attacking people.
- Give actionable, good-faith feedback.
- Respect privacy and avoid posting another person's personal information.
- Accept maintainer decisions about project scope and moderation.

## Unacceptable behavior

The following is not acceptable:

- Harassment, threats, insults, discriminatory remarks, or sexualized attention.
- Publishing private information without permission.
- Deliberate disruption, spam, or repeated off-topic behavior.
- Retaliation against someone who raises a good-faith concern.

## Reporting and enforcement

For ordinary project disagreements, use the relevant issue or pull request and keep discussion technical.

For a sensitive conduct concern, do not post personal details publicly. Open a minimal issue titled `Community conduct contact request` without sensitive details so the maintainer can establish an appropriate private channel.

Maintainers may edit or remove comments, close or lock conversations, reject contributions, or restrict participation when necessary to protect the community.

## Scope

This code applies in the repository and in other project spaces when someone is representing Resume Craft.
