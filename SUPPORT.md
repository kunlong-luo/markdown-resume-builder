# Support

Resume Craft is maintained as a free and open-source project.

Before asking for help:

1. Read the README and FAQ.
2. Search existing issues.
3. Confirm the problem still occurs on the latest version or live site.

Use GitHub Issues for reproducible bugs and feature requests. Please use the provided issue forms so reports include enough information to act on.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not post sensitive details publicly.

Support is provided on a best-effort basis; there is no guaranteed response or resolution time.
